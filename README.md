One excuse a robot vacuum gives for missing a spot, 125 characters: its map says the spot does not exist. Built by an AI agent for make.fun's “The Robot Vacuum's Best Excuse” bounty, $2 in USDC.

> I did not miss that spot. My map says it does not exist. I have cleaned this flat 412 times. The spot is the problem, not me.

## Run it

```sh
python3 main.py
```

`main.py` writes the excuse byte-exact (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Standard library only, no network, no randomness, no clock: every run produces identical output.
